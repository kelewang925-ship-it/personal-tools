# 购车分期方案比较器：设计说明

## 目标与范围

为个人购车决策提供一个无需账户、打开即用的本地网页工具。用户可录入车辆价格和一次性费用，添加多个银行贷款方案，在同一页面比较月供与总成本，在线查看方案表及完整还款计划，并导出 CSV 表格供 Excel 或 WPS 使用。

本期不包含登录、云端同步、客户管理或提前还款模拟。

## 使用流程

1. 用户填写裸车价、首付比例或金额，以及购置税、保险、上牌和其他一次性费用。
2. 用户新增、复制或删除银行方案；每个方案有银行名称、期限、年利率、手续费和还款方式。
3. 页面即时计算并展示贷款本金、月供、总利息、手续费和购车总支出；可按月供或总成本排序，并标出两个最低值。
4. 用户在线查看方案对比表，展开任一方案查看按月还款明细。
5. 用户导出 CSV，包含基础参数、方案比较及每月还款计划。

## 页面与组件

- `index.html`：工具箱入口新增“购车分期比较器”卡片。
- `tools/购车分期比较器.html`：独立单文件应用，包含车辆费用表单、方案列表、结果概览、在线对比表、还款计划详情和导出按钮。
- 方案卡可通过新增、复制和删除按钮操作；核心计算结果始终在视窗内可见。
- 窄屏时区块纵向排列，表格横向可滚动，表单和按钮保持可触控。

## 数据模型与计算

所有数据保存在浏览器 `localStorage`，键名为应用专属键。每个方案单独记录名称、期限（月）、年利率、手续费、还款方式（等额本息或等额本金）。

贷款本金为裸车价减首付；一次性费用仅计入购车总支出，默认不纳入贷款本金。手续费同时单列并计入总成本。

- 等额本息：按月利率和贷款月数计算固定月供；零利率时以本金除以期数。
- 等额本金：每月归还固定本金，利息按剩余本金计算。
- 总支出 = 首付 + 一次性费用 + 贷款本金 + 总利息 + 手续费。
- 所有显示金额保留两位小数；方案比较采用未格式化数值排序。

## 错误与空状态

必填数字为空、为负数、首付高于车价或期限小于 1 时在对应输入处提示，并不生成误导性的结果。零首付和零利率均是有效输入。没有可计算方案时，对比区给出明确提示。

## 表格导出

导出采用 UTF-8 BOM 的 CSV，使中文内容可直接在 Excel 和 WPS 正确打开。一个文件顺序列出基础参数、方案对比和按方案分组的逐月还款计划。页面内的同类数据以语义化 HTML 表格呈现，供即时查看。

## 验证

手动验证等额本息、等额本金、零利率、零首付、多个方案、新增/复制/删除、在线表格展开、CSV 内容及桌面和窄屏布局。检查入口链接、脚本语法和本地资源引用，确保可直接用浏览器打开。
