# Personal Tools

轻量、直接、打开即用的个人网页工具箱。所有功能都在浏览器本地运行，不需要安装、登录或第三方服务。

## 在线访问

[打开工具箱](https://kelewang925-ship-it.github.io/personal-tools/)

GitHub Pages 从仓库根目录的 `index.html` 提供工具入口。

## 工具列表

### 购车分期比较器

[打开工具](./tools/购车分期比较器.html)

- 添加、复制和删除多个银行贷款方案
- 比较月供、总利息、手续费和购车总支出
- 支持等额本息与等额本金，并在线查看逐月还款计划
- 导出包含基础参数、方案对比和明细的 CSV 表格
- 数据只保存在当前浏览器

### 拓印图片查看器

[打开工具](./tools/拓印图片查看器.html)

- 移动端全屏查看本地图片
- 支持缩放、拖动、10 像素位移、锁定和收起工具栏
